# Тестирование мобильного приложения «Яндекс Метро»

## Цель работы
Необходимо протестировать работу новой функциональности приложения «Яндекс Метро» на мобильном устройстве.

### Задачи:
- Протестировать те части продукта, которых коснулись изменения.
- Провести регрессионное тестирование.
- Оформить баг-репорты после тестирования.

Регрессионное тестирование: [KE_and_GZ](./KE_and_GZ.pdf)
